# Global Markets, Investments & Analytics (BUS 520) Course Materials

Welcome to the central repository for our MBA coursework (BUS 520) at Becamex Business School, Eastern International University. This repository contains the Python code, datasets, and interactive Streamlit applications utilized in our coursework.

## Overview

This repository provides hands-on resources for data analysis, econometric modeling, and financial market visualization. Students will use these materials to build and interact with web application dashboards.

## Repository Structure

* **`Python_installation/`**: Contains detailed instructions and reference materials for configuring your Python development environment.
* **`Week/`**: Houses the weekly course materials (also available in Moodle), exploratory data analysis scripts, and Streamlit implementation files.
* **`requirements.txt`**: Lists the necessary Python packages and dependencies required for the coursework.

## Getting Started

To ensure all scripts and dashboards run correctly, please follow these initial setup steps:

1. **Install Python & Tools:** Navigate to the `Python_installation` folder and follow the provided instructions to set up your environment before proceeding to the course materials.
2. **Install Dependencies:** Once your environment is configured, install the required packages using the provided `requirements.txt` file located in the main directory.
3. **Access Weekly Content:** Proceed to the weekly folders (e.g., `Week1`) to begin working with the datasets and building interactive dashboards.

If you have any questions during the setup process or encounter issues with the web applications, please feel free to ask during our sessions.
